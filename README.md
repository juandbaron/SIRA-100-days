# SIRA Guinea — 100-Day Implementation Pact Dashboard

This version updates the earlier SIRA dashboard rather than rebuilding it.

## What changed
- Replaced the earlier illustrative register with the agreed five management groups.
- Added the full working action list.
- Added legal/management basis, target timing, evidence of completion, blockers and additional information required.
- Added a dedicated "Information needed" screen.
- Added group and status filters.
- Preserved the mobile-first Country Director dashboard design.

## Important
Current implementation status has intentionally been set to **To confirm** unless factual status information was available.
The target "20 contracts signed by effectiveness" is retained as a management target and should be confirmed package-by-package for procurement and financing compliance.

Open `index.html` in a browser. No server is required.


## Version 5 update
- Effectiveness remains the first progress box.
- Groups 2–5 now appear directly underneath as progress boxes in the same visual style.
- Clicking each Group 2–5 progress box opens the activity list for that group.
- Removed Items requiring attention.
- Removed the separate Implementation by group list.
- Removed Priority actions and the redundant related view.
